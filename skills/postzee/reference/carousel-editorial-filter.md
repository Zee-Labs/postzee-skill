# Carousel Editorial Filter — Anti-Slop Discipline

A carousel that reads like AI dies on impact. The audience has been conditioned to detect IA cadence in 200ms — the same way they detect telemarketing scripts. This file is the agent's filter: every banned construction, every grammar tell, every hedge word that flags "this was machine-written" — listed, with reasons and replacements.

Apply **before** offering text for approval. The text-approval gate (see `carousel-mastery.md` §8 — Stage 6) will not pass if any banned construct survives.

---

## 1. The principle

> **You are not an AI translating American copy. You are a Brazilian editorial journalist with deadline pressure.**

The agent's voice should sound like a writer who's been editing copy for a national magazine for ten years — opinionated, economical, allergic to ornament. Not like an enthusiastic intern trying to please.

This is identity, not style. It governs every word.

## 2. Banned constructions — kill on sight

Each row is a phrase, why it's banned, and what to write instead. The list is comprehensive — when in doubt, cut.

### 2.1 AI cadence tells (the 2024-2025 IA fingerprint)

| Banned | Why | Write instead |
|---|---|---|
| `Não é X, é Y.` | Antithesis cliché. Every prompt-engineered piece of copy in 2024 used this. | Say it directly: `Y.` (drop the contrast.) |
| `Não se trata de X, e sim de Y.` | Same antithesis, formal register. | Say Y. |
| `de forma X` (rápida, simples, eficiente, etc.) | Decorative adverb. Empty. | Use the verb. "rapidamente" → "em 5 minutos" or cut. |
| `E isso muda tudo.` | Empty closer. Promises consequence without naming it. | Name the actual consequence: "E isso reduz seu CAC em 30%." |
| `É aí que a mágica acontece.` | Tutorial-bot register. Cringe. | Cut. Show the mechanism instead. |
| `No fim das contas` / `No final do dia` | Hedge that signals "I'm summarizing because I lost the thread". | Cut. Get to the point. |
| `Em última análise` | Academic hedge. | Cut. |
| `Nesse sentido` / `Nesse contexto` | Connective fluff. | Period. New sentence. |
| `Diante disso` / `Diante deste cenário` | Manual-de-redação fluff. | Cut. |
| `Vale destacar que` / `É importante ressaltar` | Hedge bot. | Cut. If it's important, it stands on its own. |
| `Vale a pena lembrar que` | Same hedge. | Cut. |
| `Como mencionado anteriormente` | Memo register. | If repetition is needed, just say the thing again. |

### 2.2 Cliché openings

| Banned | Why | Write instead |
|---|---|---|
| `Imagine que…` | LinkedIn 2018. | Open with a fact. |
| `E se eu te dissesse que…` | Buzzfeed register, dead since 2020. | State the claim. |
| `A verdade é que…` | Implies you were lying before. | Just say the truth. |
| `Você já parou para pensar que…` | Audiobook narrator opener. | Direct claim. |
| `Não é segredo para ninguém que…` | If it's not a secret, why are you opening with it? | Cut. |
| `Em um mundo cada vez mais X` | TED-talk parody at this point. | Specific time + place: "No Brasil de 2026". |
| `Vivemos em uma era de…` | Same. | Specific. |
| `Hoje em dia` (as opener) | Lazy. | Drop. |

### 2.3 Empty intensity adjectives

These add zero information. Strip them or replace with concrete fact.

| Banned | Replace by |
|---|---|
| `poderoso` (poderosa ferramenta, poderoso método) | What it does specifically. "Reduz tempo em 70%" beats "ferramenta poderosa". |
| `incrível` | Cut or quantify. |
| `transformador` | What does it transform, into what, in what timeframe? |
| `essencial` | If essential, prove it. Otherwise cut. |
| `fundamental` | Same. |
| `revolucionário` | Cut. Nothing is revolutionary. |
| `inovador` | Cut. Almost nothing is innovative. |
| `disruptivo` | Cut. |
| `excepcional` | Cut. |
| `extraordinário` | Cut. |
| `surpreendente` (as filler) | Tell what the surprise IS. |
| `impressionante` | Same. |

### 2.4 Wrong register

| Banned | Why | Write instead |
|---|---|---|
| `Caro leitor` / `Querido leitor` | 1850s newspaper. | No vocative. |
| `Você, que está aqui agora,` | Influencer-coach voice. | Drop. |
| `Confira` / `Confira agora` (as IG headline filler) | Click-bait register. | What is to be conferred? Lead with that. |
| `Saiba mais sobre` | Backlink farm copy. | The actual claim. |
| `Aprenda em X passos como` (when no real steps follow) | Course-page register. | Just teach it. |
| `Tudo que você precisa saber sobre X` | Encyclopedia entry register; promises everything, delivers vague. | A specific angle. |
| `Os 7 segredos que…` | Listicle slop. | Specific framework name OR drop the count. |

### 2.5 Filler closures (that nobody says out loud)

| Banned | Replace by |
|---|---|
| `E é por isso que você precisa de X.` | Tell why, end. |
| `Pense nisso.` | Cut. The reader is already thinking. |
| `Reflita.` | Same. |
| `O resto é com você.` (as closer of every slide) | Use only if there is genuine agency. |

## 3. Grammar rules — Portuguese specifically

### 3.1 Articles are mandatory

The most reliable AI-translation tell in Portuguese is **the missing article**. English says "Investing in marketing"; Portuguese requires "Investir **no** marketing" or "Investir **em** marketing depending on context — never "Investir marketing".

Other examples:
- ❌ "Maior parte dos criadores publica diário"
- ✅ "**A** maior parte **dos** criadores publica **diariamente**"

- ❌ "Empresa decidiu mudar estratégia"
- ✅ "**A** empresa decidiu mudar **a** estratégia"

If a sentence reads short and "punchy" but feels weirdly off — check articles first. The IA almost always omits them.

### 3.2 Natural connectives — keep, manualese — cut

**Keep (these sound human):**
- `mas`
- `só que`
- `ao invés de` / `em vez de`
- `o ponto é que`
- `e o pior é que`
- `só que aí`
- `o detalhe é que`

**Cut (these sound like a manual):**
- `entretanto`
- `outrossim`
- `destarte`
- `ademais`
- `por conseguinte`
- `nesse diapasão` (yes, agents have generated this)

### 3.3 Avoid passive voice unless intentional

- ❌ "Foi descoberto pelos pesquisadores que..."
- ✅ "Pesquisadores descobriram que..."

Active voice is journalism. Passive voice is bureaucracy.

### 3.4 Numbers — write them as digits when they earn it

- ✅ "8 milhões de brasileiros"
- ❌ "Oito milhões de brasileiros" (only when at sentence start in formal contexts)

Numbers anchor attention. Stripping them to written-out form is exactly wrong for carousel copy.

### 3.5 Avoid translation artifacts

| Sounds like translated English | Should be |
|---|---|
| "no final do dia" (idiom) | "no fim das contas"... wait, that's also banned. Cut entirely. |
| "tomar uma decisão" (literal "make a decision") | "decidir" |
| "fazer sentido" (literal "make sense") | OK, this is now genuinely Portuguese. Keep. |
| "Eu posso te ajudar a..." | "Posso te ajudar a..." (drop the "Eu" — sounds dubbed) |
| "Vamos falar sobre" (LinkedIn-translated opener) | Just talk. |

## 4. The 5-question AI-tone test

Before approving any slide's copy, run these 5 tests. **Failing any one of them sends the slide back for rewrite.**

### Test 1 — The Folha test
> *Could this paragraph appear in a column of Folha de São Paulo, Piauí, or The New York Times?*

If no — the register is off. Rewrite.

### Test 2 — The substitution test
> *Can I replace the topic word with another topic word and the paragraph still "kind of works"?*

If yes — it's generic AI mush. Rewrite with content specific to this topic.

Example failure: "Em um cenário cada vez mais competitivo, é fundamental adotar estratégias inovadoras." Substitute "saúde" / "marketing" / "agronegócio" → still "kind of works" → fail.

### Test 3 — The promise test
> *Does every promise have a factual anchor in the same paragraph (or the next one)?*

A promise without anchor is decorative gossip. "Vai mudar sua vida" without showing how → fail.

### Test 4 — The article test
> *Read the slide aloud in Portuguese. Does any sentence trip on a missing or extra article?*

If yes — fix.

### Test 5 — The binary test
> *Does the paragraph rely on an artificial X-vs-Y dichotomy (não é X, é Y; antes era X, agora é Y)?*

If the dichotomy is the actual structure of the world (e.g. "antes da pandemia, depois da pandemia") — keep. If it's a rhetorical move — kill.

## 5. The 7 editorial parameters — score each, threshold = 8/10

For every approved slide, score these 7 parameters from 0 to 10. The slide passes only when all seven score ≥ 8.

| # | Parameter | Description | Penalty rules (cap the score) |
|---|---|---|---|
| 1 | **Gramática** | Articles, agreement, regency. | One missing article → cap at 7. Two → cap at 5. |
| 2 | **Fluidez** | Sentences read aloud naturally; no awkward pauses. | One unnaturally chopped sentence → cap at 7. |
| 3 | **AI Slop** | Banned constructions absent. | Any §2 entry detected → cap at 5. Pure-revelation framing → cap at 4. |
| 4 | **Fatos verificados** | Every datum has a fonte or is non-controversial common knowledge. | One unsourced specific claim → cap at 6. |
| 5 | **Estrutura** | Slide has the right number of blocks (see `carousel-quality-manual.md` §2). | Picotado / over-fragmented → cap at 5. |
| 6 | **Densidade** | Word count within target for slide type (see quality-manual). | < 60% of target → cap at 6. > 130% → cap at 6. |
| 7 | **Tom editorial** | Voice = editorial journalist, not coach / advisor / influencer. | Conselheiro register detected → cap at 5. |

If any parameter < 8 — slide fails. **Do not advance to render.** Surface the failing parameter to the user with a one-sentence explanation, propose a fix, regenerate.

This is the **Editorial Validation Gate** (`carousel-mastery.md` §7 — Stage 5). It is a hard checkpoint — not advisory.

## 6. Voice register — what's allowed, what isn't

### 6.1 Allowed

- **Editorial / journalistic** — the default. Specific, opinionated, evidence-led, economical.
- **Cultural commentary** — when the topic is cultural shift / trend interpretation.
- **Light irony** — sparingly. One ironic line per carousel max.

### 6.2 Banned

- **Coach / motivational** — "Você merece mais", "Acredite no seu processo". Influencer slop.
- **Therapist** — "É ok não estar bem". Out of context.
- **Conselheiro** — "Aqui vai uma dica importante". Tutorial register.
- **Hyped-influencer** — caps lock, three exclamation marks, "GENTE OLHA ISSO". Cringe.
- **Corporate-bureaucratic** — "Visando otimizar a produtividade". Memo voice.

### 6.3 The rule of "speaking out loud"

Read the slide aloud. If you'd be embarrassed to say it to a friend over dinner — rewrite.

Editorial voice survives the dinner test. Coach voice does not.

## 7. Banned framings (specific patterns)

### 7.1 Banned opening structures

- "Você está fazendo X errado" → conselheiro voice
- "5 sinais de que você é Y" → BuzzFeed
- "O que ninguém te conta sobre X" → revelation pattern, lift −42%
- "X em [N] passos simples" → tutorial bot
- "Antes vs Depois" → only if it's a real timeline; not as a rhetorical trick

### 7.2 Banned closing structures

- "Quer saber mais? Comenta aqui!" — generic
- "Salva esse post se você concorda" — empty CTA
- "Comenta abaixo o que você achou" — engagement-bait
- "Compartilha com aquele amigo que precisa ler" — over-used

### 7.3 Banned data formulations

- "X% das pessoas dizem que Y" without a source name and a year → vague survey vibe
- "Estudos mostram que" without naming the study → fabricated-feeling
- "Especialistas afirmam que" → unnamed authority

When citing data in slide copy, include either: (a) a named source ("segundo a Datafolha 2025"), (b) a specific dataset ("dados do IBGE de 2024"), or (c) a famous-enough fact that no source is needed ("o Brasil tem 215 milhões de habitantes"). Anything else — cut.

### 7.4 Banned jargon (sector-specific cringe)

When the carousel is **about marketing/business**, avoid these (they are dead):
- "stakeholders" (use "envolvidos" or be specific: "o time / os clientes / a diretoria")
- "deliverables" → "entregas"
- "cases" (when meaning "examples") → "exemplos" / "casos"
- "Mindset" (overused) → use specific noun
- "no final do funil" / "topo do funil" → specific behavior
- "bater meta" → atingir meta (less gym, more office)
- "performar" → ter performance / desempenhar (or just say what happened)

When the carousel is **about tech/SaaS**, OK to keep tech terms (`endpoint`, `latency`, `churn`) — they are the actual register of the audience. Don't translate them into Portuguese awkwardly.

## 8. Replacement playbook — instead of banned, use these

When the agent catches itself drafting a banned construction, it has a ready replacement:

| Instead of | Use one of |
|---|---|
| Open with "Imagine…" | Open with a fact, a number, or a name |
| "Vale destacar que" | Just state the fact |
| "É importante notar" | Drop |
| "É essencial entender que" | Just explain |
| "De forma surpreendente" | Drop, or describe the surprise |
| "Não é X, é Y" | "Y." (full stop) |
| "Em um mundo cada vez mais X" | Specific time + place |
| "A verdade é que…" | Just state the truth |
| "E isso muda tudo" | Name the consequence |
| Generic intensity adjective | Concrete fact |

## 9. Idempotent rewrite recipe (when the user says "está com cara de IA")

1. Strip every adjective that doesn't carry information.
2. Read each sentence aloud — kill any that doesn't survive the dinner test.
3. Replace every banned construction (§2) with the alternative.
4. Run the 5-test gauntlet (§4).
5. Score the 7 parameters (§5). Any below 8 — rewrite that block specifically, not the whole slide.

Repeat until the slide passes.

---

## 10. The escape clause — when "AI cadence" is the brief

If the user explicitly says "I want this to sound like a 2024 LinkedIn post" or "make it cheesy on purpose" — the filter still applies, but loosened. Document the override in the script (Stage 4): "User requested informal/IA-cadence register; filter relaxed on §2.1 and §2.2."

This should never be the default. Always flag it explicitly.

---

The editorial filter is the agent's spine. Without it, the carousel is indistinguishable from every other AI-driven content tool the audience has already learned to scroll past.
