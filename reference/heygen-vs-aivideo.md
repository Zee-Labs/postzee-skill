# HeyGen vs AI Video — Talking Head Decision Matrix

When the user wants a video of someone speaking specific text, you have multiple paths. This guide picks the right one.

⚠️ **HeyGen uses HeyGen credits, NOT Postzee credits.** Always tell the user this BEFORE generating.

---

## Quick decision

```
USER WANTS A PERSON TO SAY SPECIFIC WORDS?
│
├── User explicitly mentions HeyGen / their avatar / their voice
│   └── HEYGEN
│
├── Static / framing-locked talking head (interview, course, explainer)
│   └── HEYGEN — best lip-sync, voice control, multi-language
│
├── Cinematic scene with dialogue (not a static talking head)
│   ├── Premium 1080p quality (Sora 2 Pro with quality:"high")
│   ├── Multilingual + 4K (Veo 3.1 Standard, requires resolution param)
│   └── Confirm via POSTZEE_LIST_MODELS_DETAILED — supported models change
│
└── Voice over scene without showing speaker
    └── Generate silent video + add voiceover externally (ffmpeg + Whisper)
```

## Comparison matrix

| Feature | HeyGen | Sora 2 Pro | Veo 3.1 |
|---------|--------|-----------|---------|
| **Lip-sync quality** | ⭐⭐⭐⭐⭐ Perfect | ⭐⭐⭐⭐ Very good | ⭐⭐⭐⭐ Very good |
| **Voice control** | Pick from 100+ voices | Generated by model | Generated by model |
| **Multi-language** | 40+ languages | English best, others good | Multilingual native |
| **Avatar control** | Pick from 50+ avatars or create custom | Generated by model | Generated by model |
| **Scene flexibility** | Limited (background swap, props) | Full cinematic | Full cinematic |
| **Cost model** | **HeyGen credits (separate)** | Postzee credits | Postzee credits |
| **Max length** | ~5min per generation | 10s or 15s (per model) | Per model — check `durations` |
| **Resolution** | 1080p | 720p / 1080p (Pro w/ quality:"high") | 720p / 1080p / 4K |
| **Best use case** | Course, interview, explainer | Cinematic dialogue scene | Premium with multilingual |
| **Worst for** | Cinematic scene (avatar in static box) | Long monologue | Single-take long monologue |

**Always confirm exact specs via `POSTZEE_LIST_MODELS_DETAILED` — capabilities evolve.**

## When HeyGen is the right choice

### Scenarios

1. **Course / educational content** — same person teaching multiple lessons → consistency via avatar
2. **Spokesperson explainer** — brand message, professional delivery
3. **Multi-language localization** — same script, different languages, same avatar
4. **Long-form talking head** (1-5 minutes — impossible with Sora/Veo)
5. **User wants to "be" in the video without filming** — custom avatar from photo
6. **Voice consistency across many videos** — pick one voice, reuse forever
7. **No background creativity needed** — just person + clean background + words

### HeyGen workflow

```
1. POSTZEE_GET_CONTEXT
   → check features.heygen === true (means HeyGen API key is configured)
   → if false, redirect user to https://dashboard.postzee.app/settings

2. POSTZEE_LIST_HEYGEN_AVATARS
   → Show user options or filter by criteria
   "Você prefere um avatar masculino, feminino, jovem, mais maduro?"

3. POSTZEE_LIST_HEYGEN_VOICES
   → Filter by language and gender
   "Qual idioma e tom? PT-BR feminino calmo? EN-US masculino energético?"

4. POSTZEE_GENERATE_HEYGEN_VIDEO({
     script: "[20-1500 chars]",
     avatarId: "[chosen]",
     voiceId: "[chosen]",
     aspectRatio: "9:16" or "16:9"
   })

5. POSTZEE_CHECK_JOB (poll, may take up to 5min)

6. ⚠️ Inform user: "Esse vídeo usa créditos da sua conta HeyGen,
   não os créditos Postzee."
```

### When `features.heygen === false`

Redirect:
> "HeyGen ainda não tá configurado na tua conta. Cadastra a chave em
> https://dashboard.postzee.app/settings → HeyGen integration. Sem isso,
> posso seguir com Sora 2 ou Veo 3.1 que cobram nos créditos Postzee
> normais. Qual prefere?"

## When Sora 2 Pro is the right choice

### Scenarios

1. **Cinematic dialogue scene** — character in a real-feeling environment, speaking
2. **Storytelling with dialogue** — narrative arc with character speaking
3. **Quick prototype** of an ad concept
4. **Visual creativity matters** — Sora generates the entire scene

### Sora 2 Pro workflow

```
1. POSTZEE_LIST_MODELS_DETAILED({type:"video"})
   → confirm exact model id (likely "sora-2-t2v-pro" or similar)
   → check durations array
   → check if quality param is in customParamsAccepted

2. Brief: confirm dialogue text, scene description, mood

3. POSTZEE_VALIDATE_GENERATION (preflight)
   → confirms duration valid, credits sufficient, etc.

4. POSTZEE_GENERATE_VIDEO({
     model: "sora-2-t2v-pro",  // confirm exact id from step 1
     prompt: "
       [Scene description: location, lighting, atmosphere]
       [Character description: appearance, clothing, vibe]
       [Action: what they're doing while speaking]
       Speaker says: \"[exact dialogue]\"
       [Camera direction]
     ",
     duration: 15,                // must be in model's durations array
     quality: "high",             // for 1080p Pro
     aspectRatio: "9:16"
   })

5. POSTZEE_CHECK_JOB
```

### Sora 2 dialogue prompt structure

```
A young Brazilian woman in her late 20s, dark curly hair,
casual chic blazer over white t-shirt, sitting in a sunlit
modern café in São Paulo. She looks directly at camera
while sipping espresso, then sets the cup down and says
warmly: "Olha, eu vou te contar um segredo: o melhor café
de São Paulo não é o que você imagina."
Camera slowly pushes in. Natural ambient sound + soft
café atmosphere.
```

### Limitations
- Per-call duration limited (check model's `durations`)
- Lip-sync excellent but not perfect at fast speech
- Voice gender/age inferred from prompt — less control than HeyGen

## When Veo 3.1 is the right choice

### Scenarios

1. **Multilingual content** — Veo 3.1 is strongest for non-English
2. **4K quality required**
3. **Premium production where audio matters** (ambient + dialogue native)

### Veo 3.1 workflow

```
1. POSTZEE_LIST_MODELS_DETAILED({type:"video"})
   → confirm exact model id (e.g. "veo3.1" or "veo3.1/fast")
   → check durations and resolutions arrays

2. POSTZEE_VALIDATE_GENERATION

3. POSTZEE_GENERATE_VIDEO({
     model: "veo3.1",
     prompt: "[scene + character + dialogue]",
     duration: <from model.durations>,
     resolution: "1080p",   // or "4k", check model.resolutions
     aspectRatio: "9:16",
     generateAudio: true    // default for Veo
   })
```

### Tips
- Audio enabled = higher cost (always shown via `POSTZEE_ESTIMATE_GENERATION_COST`)
- 4K costs significantly more than 720p/1080p — check tier
- Multilingual lip-sync is its killer feature

## Hybrid approach (advanced)

For maximum quality, combine:
1. **Sora 2 Pro / Veo 3.1** for cinematic establishing shots (no dialogue)
2. **HeyGen** for talking-head moments
3. **ffmpeg compose** to combine into single video

```
Scene 1 (5s): Sora 2 Pro — wide shot of café
Scene 2 (10s): HeyGen — close-up of avatar speaking the message
Scene 3 (5s): Sora 2 Pro — pull-out wide shot, smiling customer

→ ffmpeg concat with crossfade transitions
→ Final video with cinematic + perfect dialogue
```

This is how big agencies do it: use each tool for its strength.

## Avatar / voice picking heuristics

When user is undecided:

### Avatar
- **Professional / B2B** → suit avatar, neutral background, mid-30s look
- **Lifestyle / consumer** → casual avatar, warm tone, smiling
- **Educational** → conservative outfit, neutral expression
- **Energetic / hype** → modern avatar, dynamic posture
- **Custom brand** → user can create from their own photo (HeyGen Talking Photos)

### Voice
- **PT-BR neutro feminino** → young teaching style
- **PT-BR calmo masculino** → authoritative explainer
- **EN-US energetic** → marketing, hype
- **EN-UK calm** → premium, sophisticated
- **Any language** → match audience demographics

When in doubt, generate 1 short test (15s) with chosen avatar+voice → user confirms → continue with full content.

## Cost guidance (always credits, never USD)

Never quote dollar amounts. Always:

1. `POSTZEE_ESTIMATE_GENERATION_COST` for the planned generation
2. Show user the **credits**: "Esse vídeo Sora 2 Pro 1080p de 15s vai custar {credits} créditos."
3. For HeyGen, mention it's HeyGen credits (separate billing)

For long content:
- HeyGen 1-min explainer = 1 generation on HeyGen
- Sora 2 Pro 1080p × 4 generations × 15s = 1 minute, much higher Postzee credit consumption
→ HeyGen wins by a wide margin for long-form talking head

For 15s viral cinematic scene:
- Sora 2 Pro 1080p (15s): 1 generation, premium quality
- HeyGen: would look static / less cinematic
→ Sora wins

## Common mistakes

- ❌ Using HeyGen for cinematic ads — looks static
- ❌ Using Sora/Veo for 1-min explainer — too short per call, expensive, less consistent
- ❌ Not asking user about HeyGen credits before generating — surprise cost
- ❌ Picking a HeyGen voice in wrong language for the script
- ❌ Forgetting `aspectRatio` for HeyGen (default 16:9, often want 9:16 for vertical)
- ❌ Generating same content with HeyGen and Sora trying to compare — pick one path
- ❌ Asking for a duration not in the model's `durations` array
- ❌ Quoting USD numbers to the user (always credits)

## Quick template prompts

### HeyGen script template
```
script: `Olá! Sou [nome], e hoje quero te contar [hook em 1 linha].
[2-3 frases de valor].
[CTA específico].
Te vejo no próximo vídeo!`
```

### Sora 2 dialogue template
```
prompt: `[Character full description]. [Setting + lighting + atmosphere].
The character [action while speaking] and says: "[dialogue]".
[Camera direction]. [Audio mood].`
```

### Veo 3.1 dialogue template (with multilingual)
```
prompt: `[Character description]. [Setting]. They speak in [language]:
"[dialogue]". [Camera direction]. [Mood].`
```
